# oceanic-content-agent

Recopilar y organizar contenido oficial de las marcas náuticas
representadas por Oceanic.

Este repositorio es la base de datos y el sistema de investigación del
catálogo náutico de Oceanic. Antes de tocar nada, lee **[`CLAUDE.md`](./CLAUDE.md)**:
ahí están el objetivo, el alcance, la jerarquía de fuentes, las reglas de
"no inventar" y el workflow de fases.

Estado actual: **Fase 1 — Master Represented Brands Inventory** completado
(`data/brands/master-inventory.json`). Fase 2 (inventario de modelos) no
iniciada; requiere aprobación humana, ver `CLAUDE.md` sección 21 y
`data/changelog/brands-changelog.md`.

Arquitectura completa: [`docs/architecture.md`](./docs/architecture.md).
